MANUFACTURING GURU - Android starter project
============================================

यह Android Studio में खुलने वाला शुरुआती Kotlin + Jetpack Compose प्रोजेक्ट है।
इसमें Home screen, Hindi + English labels, 6 feature cards और basic navigation शामिल हैं।

APK बनाने के लिए:
1. कंप्यूटर में Android Studio इंस्टॉल करें।
2. इस ZIP को Extract करें।
3. Android Studio > Open > extracted ManufacturingGuru folder चुनें।
4. Gradle Sync पूरा होने दें।
5. Run दबाकर emulator या USB debugging वाले Android फोन पर टेस्ट करें।
6. APK के लिए Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।

ध्यान दें:
- यह शुरुआती prototype/source project है, Play Store release-ready final app नहीं।
- Calculator अभी placeholder जानकारी दिखाता है; वास्तविक RPM/feed calculations अगली development stage में जोड़ने होंगे।
- Play Store पर प्रकाशित करने से पहले content, privacy policy, app icon, screenshots, testing और policy compliance पूरा करें।
- Play Console account और आवश्यक testing/publishing steps आपको अपने वैध account से पूरे करने होंगे।
